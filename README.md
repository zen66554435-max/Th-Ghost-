# TH Ghost 👻 — منصة التدقيق الأمني الدفاعي

منصة فحص أمني عربية **غير تدميرية** لتطبيقات الويب، تعمل على الأهداف **المصرح بها فقط** داخل نطاق محدد صراحةً، مع مختبر تدريبي معزول وقياس موضوعي لقدرة الكشف.

## أبرز القدرات

- **حارس نطاق (Scope Guard):** تثبيت DNS عند بناء السياسة، رفض الشبكات الداخلية للأهداف العامة، حظر عناوين metadata السحابية دائماً، كشف DNS rebinding، والتحقق من كل قفزة إعادة توجيه.
- **محرك اكتشاف:** زاحف BFS + robots.txt + sitemap.xml + استكشاف OpenAPI، مع خريطة مسارات بمصدر وحالة ووقت كل اكتشاف.
- **8 محركات فحص مستقلة قابلة للتوسعة:** الخادم والإعدادات، الحقن (SQLi/XSS/SSTI/أوامر/اجتياز مسار/LDAP/XPath/ترويسات)، التحكم بالوصول (IDOR/BOLA/BFLA)، المصادقة والجلسات، أمان API، أمان الملفات، جانب العميل، منطق الأعمال.
- **محرك تحقق بمستويات ثقة أربعة:** مؤكدة / مرجحة / معلوماتية / تحتاج مراجعة يدوية — لا «مؤكدة» برسالة خطأ وحدها؛ التأكيد بعلامات خاملة وفرق سلوكي مزدوج فقط.
- **تدقيق التبعيات والمصدر:** رفع `requirements.txt` / `package-lock.json` / ملفات Python لمطابقة CVE معروفة وتحليل ساكن برقم السطر.
- **خصوصية صارمة:** لا كلمات مرور أو رموز أو بيانات شخصية في أي تقرير أو سجل — تنظيف آلي للأدلة.
- **طابور مهام + إيقاف فوري + حدود طلبات/زمن/تزامن + GET فقط افتراضياً** (POST الوحيد: تسجيل دخول حساباتك الاختبارية المصرح بها).

## التشغيل السريع

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
# افتح http://127.0.0.1:8000
```

المختبر التدريبي (معزول، 127.0.0.1 فقط):

```bash
python3 lab/lab_server.py    # http://127.0.0.1:8765
```

التقييم الموضوعي على المختبر:

```bash
python3 scripts/evaluate.py --write-docs
```

تفاصيل كاملة في [docs/RUN_AR.md](docs/RUN_AR.md) ونتائج القياس في [docs/EVALUATION_AR.md](docs/EVALUATION_AR.md).

## حدود صريحة

لا يدّعي TH Ghost كشف جميع الثغرات بلا استثناء. النتائج «مرجحة/تحتاج مراجعة» تتطلب تأكيداً بشرياً، والفحص مبني على GET غير تدميري — لا brute force ولا DoS ولا تعديل بيانات.

## البنية

```
app/
  main.py       واجهة FastAPI + لوحة التحكم
  scope.py      حارس النطاق ومنع SSRF
  net.py        طبقة الجلب الآمن (معدل/تزامن/مهلة/ميزانية)
  crawler.py    محرك الاكتشاف
  verify.py     محرك التحقق ومستويات الثقة
  scanner.py    المنسق   jobs.py  الطابور   db.py  التخزين
  engines/      المحركات الثمانية + deps.py (تدقيق التبعيات/المصدر)
  static/       لوحة التحكم العربية RTL
lab/            المختبر التعليمي + ground_truth.json
scripts/        evaluate.py (قياس P/R/F1) + verify_live.py (تحقق حي)
tests/          127 اختباراً (وحدات + API + تكامل + تقييم)
```
