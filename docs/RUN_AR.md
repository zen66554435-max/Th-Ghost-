# دليل التشغيل — TH Ghost

## 1) المتطلبات

- Python 3.11+ (طُوّر واختُبر على 3.12)
- التبعيات في `requirements.txt`:

```bash
pip install -r requirements.txt
```

## 2) تشغيل المنصة

```bash
cd TH_Ghost
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

افتح `http://127.0.0.1:8000` — لوحة تحكم عربية كاملة (RTL).

> قاعدة البيانات `th_ghost.db` تُنشأ تلقائياً بجانب مجلد المشروع عند أول تشغيل.

## 3) تشغيل المختبر التدريبي

```bash
python3 lab/lab_server.py        # يعمل على http://127.0.0.1:8765
```

المختبر معزول: يرتبط بـ 127.0.0.1 فقط، بلا أوامر نظام، وبياناته وهمية بالكامل،
وثغراته محاكاة بمحتوى تعليمي جاهز.

## 4) أول فحص (خطوة بخطوة)

1. من تبويب **المواقع** → «+ إضافة موقع»: الاسم أي اسم، العنوان `http://127.0.0.1:8765`، النطاق `/`.
2. (اختياري) زر **الحسابات** على المشروع → أضف `labuser1 / labpass1` و`labuser2 / labpass2` —
   حسابات اختبارية يستخدمها محرك التحكم بالوصول للمقارنة متعددة الصلاحيات.
3. زر **فحص** → اختر العمق (متوسط مناسب) وأنواع الفحص → بدء. تقدّم الفحص يظهر حياً في تبويب **الفحوصات**.
4. **التفاصيل** → النتائج مع فلاتر الشدة/الثقة/الفئة، وبطاقة كل نتيجة تعرض: الدليل المنظّف، السبب، الأثر، الإصلاح، المرجع، وطريقة إعادة الاختبار، وCVSS حيث ينطبق.
5. **تقرير Markdown** أو **تصدير JSON** من أعلى تفاصيل الفحص.
6. **إعادة الفحص** يعيد التشغيل بنفس الإعدادات المخزنة.

## 5) تدقيق التبعيات والمصدر

من زر **تدقيق تبعيات** على المشروع: ارفع `requirements.txt` أو `package-lock.json`
أو ملفات `*.py` (حتى 10 ملفات × 2MB). تُسجَّل النتائج كفحص في السجل.

ملاحظة مهمة: تدقيق المصدر يعمل على الملفات التي ترفعها أنت — الفاحص لا يدّعي
استنتاج ثغرات كود داخلي من عنوان URL وحده.

## 6) قياس قدرة الكشف (Precision/Recall/F1)

```bash
python3 scripts/evaluate.py --write-docs
```

يشغّل مختبراً على منفذ حر، يفحصه فحصاً كاملاً، يقارن بـ `lab/ground_truth.json`
(الحقيقة المرجعية)، ويكتب `docs/EVALUATION_AR.md` + `docs/evaluation_result.json`.
يفشل الأمر (رمز خروج 1) إن هبطت الدقة عن 85% أو الاستدعاء عن 80% أو انتُهكت ضوابط سلبية.

## 7) الاختبارات والتحقق الحي

```bash
python3 -m pytest tests/ -q          # 127 اختباراً
python3 scripts/verify_live.py       # 26 فحصاً حياً: خادم حقيقي + دورة مستخدم كاملة
```

## 8) أسئلة شائعة

- **هل يمكن فحص موقع عام؟** نعم — شرط أن يكون مصرحاً لك. حارس النطاق يرفض أي هدف
  عام يحلّ إلى عنوان داخلي/محجوز، ويحظر عناوين metadata السحابية دائماً.
- **لماذا GET فقط؟** لأن الفحص دفاعي غير تدميري. الاستثناء الوحيد: POST تسجيل الدخول
  لحساباتك الاختبارية عند تفعيل «استخدام الحسابات».
- **أين تُحفظ كلمات مرور الحسابات؟** في SQLite المحلية فقط، لا تُرجعها أي واجهة قراءة،
  ولا تظهر في التقارير ولا سجل التدقيق (تنظيف آلي).
- **الفحص بطيء؟** اختر عمق «سطحي» أو ارفع معدل الطلبات (بحد أقصى 20/ث).
